Suspension tuning bench - installable app (PWA)

1. Create a free GitHub account, make a new public repository, upload these 5 files.
2. Repository Settings > Pages > Source: main branch, root folder > Save.
3. After about 1 minute, open https://<your-username>.github.io/<repo-name>/ on your phone.
4. Android Chrome: menu > Install app.  iPhone Safari: Share > Add to Home Screen.
5. Open it once while online; after that it works offline.

To update: replace index.html and change CACHE="susp-v1" to "susp-v2" in sw.js.
